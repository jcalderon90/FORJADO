# FORJADO

Bóveda de trabajo de la agencia FORJADO (automatización + IA).

## Mapa

- **`CLIENTES/`** — todo lo específico de cada cliente. Ver `CLIENTES/_Léeme.md` y el `INDEX.md` de cada subcarpeta antes de abrir archivos sueltos.

Para el estado consolidado y pendientes de todos los clientes en un solo lugar: `INTERNO/00 - INICIO/Estado del Proyecto.md`.
