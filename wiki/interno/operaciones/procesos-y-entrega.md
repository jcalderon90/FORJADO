# Procesos y Entrega — FORJADO

Flujo estándar desde que un cliente dice "sí" hasta el cierre. Sirve para cualquier servicio.

## 1. Onboarding
- [ ] Confirmar alcance y firmar propuesta/contrato (ver [[../templates/plantilla-propuesta|Plantilla de Propuesta]]).
- [ ] Cobrar anticipo (según [[../finanzas/modelo-de-precios|Modelo de Precios]]).
- [ ] Crear nota de proyecto ([[../templates/plantilla-proyecto|Plantilla de Proyecto]]).
- [ ] Recolectar accesos y materiales (guardar en [[../recursos/credenciales|Credenciales]]).
- [ ] Definir fechas y canal de comunicación.

## 2. Ejecución
- [ ] Dividir en hitos/entregables.
- [ ] Avances y comunicación periódica con el cliente.
- [ ] Registrar decisiones y cambios en la nota del proyecto.

## 3. Entrega
- [ ] Revisión final de calidad.
- [ ] **Compuerta QA Web/App (Auditoría 2026-11):** Pasar la **Checklist de 40 Reglas** (20 de seguridad Web/API/DB + 20 pre-lanzamiento SEO/OG/WCAG/404/anti-spam/GA4), verificar flujo y responsive en navegador real (`Playwright CLI` / `Impeccable`) y usar skeletons `CLS = 0` (`Boneyard`) cuando aplique (ver [[../recursos/catalogo-referencias-multimedia]] y [[../configuracion-skills]]).
- [ ] Entrega de resultados + documentación/handoff.
- [ ] Capacitación breve si aplica.
- [ ] Cobrar saldo restante.

## 4. Cierre
- [ ] Pedir testimonio / feedback.
- [ ] Identificar venta cruzada o retainer.
- [ ] Registrar aprendizajes.
- [ ] Mover el cliente a estado correspondiente en [[../ventas/pipeline|Pipeline]].
