# Modelo de Precios — FORJADO

## Modalidades de cobro

| Modalidad | Cuándo conviene | Cómo se cobra |
|---|---|---|
| **Por proyecto** | Alcance claro y acotado | Precio fijo (anticipo + saldo) |
| **Retainer mensual** | Trabajo recurrente (redes, mantenimiento, automatización continua) | Cuota fija al mes |
| **Por hora** | Soporte, consultoría puntual, alcance incierto | Tarifa horaria |
| **Por valor / resultado** | Impacto medible alto | % o bono sobre resultado |

## Tarifas base

| Concepto | Valor |
|---|---|
| Tarifa por hora (soporte puntual) | **$50 USD/hr** |
| Anticipo estándar | **50%** antes de empezar |
| Retainer mínimo | **$250 USD/mes** |
| Sesión de consultoría | **$120 USD** |

## Reglas de cobro
- Anticipo antes de empezar (sugerido 50%).
- Saldo contra entrega.
- Retainers se cobran por adelantado cada mes.
- Cambios fuera de alcance se cotizan aparte.
