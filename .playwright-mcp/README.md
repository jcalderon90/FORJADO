# Artefactos y Logs de Playwright MCP (`.playwright-mcp/`)

Directorio generado automáticamente por el servidor MCP de Playwright (`playwright-mcp`) durante sesiones interactivas de automatización de navegador.

> [!NOTE]
> Todos los archivos de registro (`console-*.log`) generados en esta carpeta son efímeros y están excluidos del repositorio en `.gitignore` para proteger información de sesión o datos sensibles de clientes.

---

## Propósito
- Registrar capturas de consola del navegador y trazas de navegación durante la depuración o interacción de agentes con sitios web (por ejemplo, portales de inventario o validación de formularios).
- Facilitar el diagnóstico de errores de scripting o selectores DOM en tiempo de ejecución.
