# Servicio — Automatización e IA

## Descripción
Automatizo tareas repetitivas e integro tus herramientas para que el trabajo manual desaparezca. Stack principal: **n8n** (automatizaciones y agentes de IA), **Make** como alternativa, **Claude** para agentes avanzados, y **Python/JS** cuando el proyecto requiere lógica personalizada o escalar a código.

## Problemas que resuelve
- Copiar/pegar datos entre sistemas que no se hablan.
- Responder lo mismo mil veces (soporte, FAQs, leads).
- Reportes manuales que consumen horas.
- Procesos que dependen de que alguien "se acuerde" de hacerlos.

## Entregables
- Flujo(s) de automatización funcionando y documentados.
- Integraciones entre apps (correo, CRM, Sheets, Slack, etc.).
- Agente/asistente de IA configurado para una tarea concreta.
- Documentación de cómo funciona y cómo mantenerlo.
