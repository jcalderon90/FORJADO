# Servicio — Desarrollo de Software

## Descripción
Diseño y construyo productos digitales a la medida: sitios web, aplicaciones e integraciones. Stack: **React/Next.js + TypeScript + Tailwind + shadcn** en frontend, **Node.js + Express** en backend, **MongoDB** o **Supabase (PostgreSQL)** en base de datos. Se adapta al caso y al cliente.

## Problemas que resuelve
- Necesitas una web/app y no sabes por dónde empezar.
- Tienes una idea de producto y quieres validarla (MVP).
- Herramientas genéricas no se ajustan a tu operación.
- Sistemas viejos que necesitan integrarse o modernizarse.

## Entregables
- Sitio web / aplicación funcionando y desplegada.
- Código fuente documentado.
- Base de datos y APIs según necesidad (p. ej. MongoDB).
- Manual de uso y handoff.
