# Procesos y Entrega — FORJADO

Flujo estándar desde que un cliente dice "sí" hasta el cierre. Sirve para cualquier servicio.

## 1. Onboarding
- [ ] Confirmar alcance y firmar propuesta/contrato (ver `_templates/Plantilla — Propuesta`).
- [ ] Cobrar anticipo (según [[Modelo de Precios]]).
- [ ] Crear nota de proyecto (`_templates/Plantilla — Proyecto`).
- [ ] Recolectar accesos y materiales (guardar en [[Credenciales]]).
- [ ] Definir fechas y canal de comunicación.

## 2. Ejecución
- [ ] Dividir en hitos/entregables.
- [ ] Avances y comunicación periódica con el cliente.
- [ ] Registrar decisiones y cambios en la nota del proyecto.

## 3. Entrega
- [ ] Revisión final de calidad.
- [ ] Entrega de resultados + documentación/handoff.
- [ ] Capacitación breve si aplica.
- [ ] Cobrar saldo restante.

## 4. Cierre
- [ ] Pedir testimonio / feedback.
- [ ] Identificar venta cruzada o retainer.
- [ ] Registrar aprendizajes.
- [ ] Mover el cliente a estado correspondiente en [[Pipeline (MOC)]].
